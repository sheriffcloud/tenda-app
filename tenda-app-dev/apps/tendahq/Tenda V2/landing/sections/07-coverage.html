Reframed: decentralized

Headline now says "Live wherever you are". No "launched in N countries." Subhead makes the on-chain mechanic explicit: a corridor lights up the moment a buyer + worker meet there. Section is activity, not availability.

Real-shape map via dot-density

Map renders actual continental geography (N. America, S. America, Europe, Africa, Middle East, Asia, SE Asia, Indonesia, Philippines, Japan, Australia, NZ) using a coordinate-mapped dot grid. Equirectangular projection: x = (lon+180) × 1600/360. Reads as a recognizable world map, not a cartoon, and ties visually to the dark-spine vocabulary (dots, mono labels, on-chain receipts).

Liquidity, not status

Sidebar pills now read HIGH / MED / GROWING — not LIVE / SOON. Every supported currency is "live." This communicates the real thing buyers + workers care about: how thick is this corridor right now?

Hub glows + arcs

Top-7 cities (Lagos, Manila, Nairobi, London, Mumbai, NYC, Cape Town) get blue/green radial glows + ring + label. Dashed arcs connect the biggest pairs (NGN↔PHP, etc). The glow tells you where money is moving without listing rankings.

Motion

Land dots fade in by region, stagger 40ms per group. Active dots scale-in 0 → 1 after, opacity matches volume. Hub glows expand 0.6 → 1 with breathing pulse (3s loop, 0.85 → 1.0). Corridor arcs draw stroke-dashoffset over 1.4s. Floater (LAST 30 DAYS card) slides in last.
