Colophon, not a footer

Treated like the back-matter of a system manual: oversized wordmark, mono labels with 00–04 numbering, hairline rules between every band, no decorative imagery. The page has made its case in §1–§10 — this section's job is to register, not persuade.

Wordmark band

144px tenda. with the period in accent green — the period is the brand mark across the system (auth dot, status dot, footer dot). Right side carries the live 24h volume as one final receipt; reads as "we're not a brochure, we're running."

Sitemap structure

5 columns: About (paragraph + socials, the only text block), then 4 numbered sitemap columns — Product · Workers · Posters · Resources. Audience-led split, not nav-led; mirrors the §3 / §8 audience split that runs through the page. New + Soon + count badges keep it feeling current.

Status strip = trust restated

Four cells: Systems (live dot), Settle time 24h, Validators, Contract version. This is a stripped-down version of the §6 pillars, ambient rather than declarative. If a visitor scrolls all the way down with doubt, the running numbers lay it to rest one last time.

Region + FX

Region pill on the left (flag + country + currency + language, dropdown affordance), live FX rail on the right (NGN · KES · GHS · ZAR · USDC · USDT · +8). Each currency carries a green dot — "rate is live." Same green dot grammar as the §5 ticker.

Motion

::before top hairline has a single horizontal sweep on first reveal, then static. Status dot pulses 2.4s. Volume number counts up from $0.00 on intersect. Currency pill dots blink in sequence (120ms stagger) — implies running market data.

Spacing

Section 96 80 36. Wrap max 1280. Wordmark 144/0.85/-0.06em. Cols 1.3fr / 1fr ×4 · gap 48. Status 4 cols · pad 24 0 with hairlines top/bottom. Region pill pad 10 16 · radius 999. Legal 1fr / auto · gap 32. All hairlines rgba(255,255,255,0.06–0.10).
