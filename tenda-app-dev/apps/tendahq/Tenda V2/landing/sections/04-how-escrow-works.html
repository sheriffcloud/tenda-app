FALLBACK · WHEN THINGS GO WRONG

If proof is missing or contested, escrow resolves — it doesn't disappear.

Funds are never stuck on Tenda. The program supports four exits — three automatic, one human-reviewed. Whichever path triggers, both parties see the same on-chain receipt.

AMutual cancel. Either side cancels before work starts → SOL returns to poster.~2s
BAuto-approve. Poster doesn't review within 48h of proof → release fires automatically.48h
CAuto-refund. Worker doesn't submit proof before deadline → SOL returns to poster.deadline
DDispute. Either side opens a dispute → Tenda reviewers split the locked amount based on evidence.≤ 24h

From the on-chain program

// every release is one of four paths
match escrow.state {
  Approved  → split(payout, fee),
  AutoApproved → split(payout, fee),
  Refunded  → return(poster),
  Disputed  → arbitrate(),
}

Why dark wins here

Receipt cards now read as terminal/explorer rows — the metaphor we want for trust language. Hash chips, monospace, status pills all gain saturation. Cream-version made them feel decorative; dark makes them feel technical.

Brighter accent palette

Blue lifted to #5E87E8, orange to #F0A365, green to #3ACB8E. Stage rings get a 4px outer glow at 10% alpha — sells the "node on a wire" feeling without being noisy.

Continuous dark spine

§3 (Two products, dark) → §4 (Escrow, dark) → §5 (Live ticker, dark) reads as one continuous trust passage. Light surfaces return at §6 onward.

Stage 4 inverted

Number 04 is the only filled chip — bone-white on black. Visual full-stop on "Release." Mirrors the SETTLED status pill in the same card (also inverted).

Motion

Track-rule scaleX 0→1 over 800ms on enter. Stage receipts fade up 120ms stagger. PROOF dot pulses (1.6s loop). Stage-num glows expand on hover (0 0 0 4px → 6px).

Spacing unchanged
