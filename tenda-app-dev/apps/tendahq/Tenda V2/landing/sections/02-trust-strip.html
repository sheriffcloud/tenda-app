Why this beats the literal brief

Hero already shows < 2s · 2.5% · 100% · 8 markets. Repeating those numbers in §2 = visual stutter. A live feed of actual settlements with on-chain signatures and a real program ID PROVES "100% on-chain" instead of repeating it.

Identity left, evidence center, verifiability right

Three-zone layout: who's running (program name + cluster) · what's happening (running events) · can you check (slot + explorer link). Same pattern Etherscan/Solana FM use — earns instant credibility with crypto-natives.

Motion

Feed track scrolls right→left at 50s. Pause on hover. Pulse ring on NETWORK · LIVE badge. Slot number tick-flips every ~400ms in real production (paused in wireframe). Reduced-motion → static, edge-fade only.

Spacing

Band height 88 · padding 28 80 · grid auto 1fr auto · gap 48. Right cluster border-left + padding-left 24. Mobile collapses to two stacked rows + meta.

Real data hookup

At build: query the Tenda escrow program for the last 5 settlement events. Poll /recent-settlements every 30s. Slot from connection.getSlot(). Explorer link uses live cluster + program ID.

Fallback

If RPC unreachable: freeze last-known feed + mute the LIVE pulse · show NETWORK · CACHED. Never fake the data.
