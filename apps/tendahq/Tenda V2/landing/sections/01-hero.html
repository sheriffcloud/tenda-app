Headline trick

Two-line H1: Get paid. in content.primary, No middlemen. in content.tertiary. Same hierarchy trick the v1 hero uses — preserved.

Card stack

Three layers: gig peek (back, -4°, 60%), funding state (mid, +2°, 55%, blurred), locked state (front, -2° + perspective). Implies the FUNDING → LOCKED flip and "two products" without burning a second hero.

Spacing · desktop

Hero padding 96 80 80. Grid 1fr 1fr · gap 48. min-height 720 (≈ 92svh on 1080 displays). Card width 360 · radius 24.

Type · numerics

Every number on this page is JetBrains Mono. Hero amount mono-large 40/44 · 600 · -0.02em. Countdown mono 14 · 600. Trust ticks mono-small 12 · 500.

Motion · viewport enter (one-shot)

Pill flip FUNDING → LOCKED at 220ms. SOL number count-up 0 → 2.000 at 480ms. Brand-tinted ring pulses card once. No infinite loops.

Motion · marquee

Currency strip loops 40s. Pause on hover. prefers-reduced-motion → static, fades on edges only.

Mobile sticky CTA

56h bar pinned to viewport bottom, visible only below lg. Auto-hides when in-page Download CTA scrolls into view (IntersectionObserver). Text never wraps — keep ≤ 28ch.

Eyebrow status

🟢 LIVE ON SOLANA · DEVNET — verified copy. When mainnet ships, swap to LIVE ON SOLANA · MAINNET (no other change).

Mobile breakpoints
